# Azure Databricks & PySpark

## Overview

This module demonstrates enterprise-scale data transformation, validation, and processing using Azure Databricks and PySpark.

The solution ingests data from Azure Data Lake Storage (ADLS Gen2), applies data quality validations, performs business transformations, and generates analytics-ready datasets for Data Warehouses, Microsoft Fabric, and Power BI.

This implementation simulates production-grade Data Engineering workflows commonly used in Azure environments.

---

# Objectives

- Process large datasets using PySpark
- Transform raw data into curated datasets
- Apply data quality validation rules
- Generate quality metrics
- Standardize source data
- Produce analytics-ready Parquet datasets
- Support Data Warehouse and Lakehouse architectures

# Data Quality Framework

## Objective

Validate data before promotion from Raw to Curated zones.

---

## Validation Rules

### Null Validation

Required columns:

- customer_id
- name
- city

Records failing validation are rejected.

---

### Duplicate Validation

Duplicate records are removed.

Example:

```python
df.dropDuplicates()
```

---

### Data Type Validation

Expected types:

| Column | Type |
|----------|----------|
| customer_id | Integer |
| name | String |
| city | String |

---

### Business Rule Validation

Examples:

```text
Customer ID > 0

Order Amount > 0

City cannot be blank
```

---

### Schema Validation

Checks include:

- Missing columns
- Unexpected columns
- Data type changes

Expected schema:

```text
customer_id
name
city
last_modified
```

---

### Data Freshness Validation

Verifies:

- LastModifiedDate
- Pipeline Timestamp
- Source Data Age

# PySpark Examples

## Read CSV

```python
df = spark.read.csv(
    "customers.csv",
    header=True
)
```

---

## Remove Duplicates

```python
df_clean = df.dropDuplicates()
```

---

## Standardize Names

```python
from pyspark.sql.functions import upper

df_clean = df.withColumn(
    "name",
    upper(df.name)
)
```

---

## Export Parquet

```python
df_clean.write.mode(
    "overwrite"
).parquet(
    "customers_parquet"
)
```
